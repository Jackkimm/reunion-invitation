# 🎉 동창회 초대장 웹앱

카카오톡으로 링크 하나만 보내면 되는 **모바일 동창회 초대장**입니다.
D-day 카운트다운 · 참석 투표(로그인 없음) · 실시간 참석자 명단 · 지도 링크가 들어 있고,
응답은 **Notion 데이터베이스**에 그대로 쌓입니다.

- **프론트**: 순수 HTML/CSS/JS (빌드 도구 없음, 모바일 우선) — `public/` 폴더
- **백엔드**: Cloudflare Functions (`/functions/api/`) — Notion API 프록시
- **DB**: Notion 데이터베이스 1개
- **비용**: Cloudflare Pages 무료 플랜 + Notion 무료 플랜으로 충분합니다

> 아이패드(사파리)만 있어도 처음부터 끝까지 할 수 있게 아래 순서대로 적었습니다.
> PC나 터미널은 필요 없습니다. **넉넉히 30분** 잡으세요.

## 📁 폴더 구조

```
.
├── public/                     ← 이 폴더가 그대로 웹사이트가 됩니다
│   ├── index.html              ← 화면 전체 (OG 메타태그도 여기 상단에 있음)
│   ├── _headers                ← 응답 헤더(보안·캐시) 설정
│   └── assets/
│       ├── css/style.css       ← 디자인
│       ├── js/config.js        ← ★ 동창회 내용은 여기만 고치면 됩니다
│       ├── js/app.js           ← 카운트다운·투표·명단 로직
│       └── img/                ← og.png (카톡 미리보기 이미지) 넣는 곳
├── functions/api/
│   ├── _notion.js              ← Notion 공용 코드 (밑줄로 시작 → 주소로 노출 안 됨)
│   ├── attendees.js            ← GET  /api/attendees
│   └── rsvp.js                 ← POST /api/rsvp
├── src/worker.js               ← Workers 진입점 (/api/* 라우팅 + 정적 파일)
└── wrangler.jsonc              ← Workers 배포 설정 (프로젝트 이름 확인 필요)
```

## 1단계 · Notion 데이터베이스 만들기

1. 아이패드에서 **Notion 앱**(또는 사파리 `notion.so`)을 엽니다.
2. 왼쪽 메뉴 아래 **`+ 새 페이지`** 를 누릅니다.
3. 페이지 제목을 **`동창회 참석 명단`** 으로 적습니다.
4. 본문에 **`/표`** 라고 입력한 뒤 나오는 목록에서 **`표 보기`(Table view)** 를 고릅니다.
   - "새 데이터베이스" 를 선택하세요. (기존 것 연결 ❌)
5. 아래 표대로 **속성(Property) 3개**를 만듭니다. **이름과 종류가 정확히 같아야 합니다.**

   | 속성 이름 | 종류 | 설명 |
   |---|---|---|
   | `이름` | 제목 (Title) | 표를 만들면 기본으로 있는 첫 번째 열입니다. 이름이 `Name`/`이름 없음` 이라면 눌러서 **`이름`** 으로 바꿔주세요. |
   | `참석여부` | 선택 (Select) | 옵션 4개를 미리 만들어 두세요 → **`축구부터`**, **`저녁부터`**, **`뒷풀이부터`**, **`불참`** |
   | `한마디` | 텍스트 (Text) | 참석자가 남기는 한 줄 메시지 |

   > 💡 속성 추가는 표 맨 오른쪽 **`+`** 버튼 → 이름 입력 → 종류 선택 순서입니다.
   > `참석여부` 옵션은 아무 행에나 값을 한 번씩 입력해 보면 만들어집니다.
   > 선택지를 늘리거나 이름을 바꾸려면 `public/assets/js/config.js` 의 `statuses` 와
   > `functions/api/_notion.js` 의 `STATUSES`, 그리고 노션 옵션 **세 곳을 모두** 맞춰야 합니다.
   > 연습용으로 넣은 행은 나중에 지워도 됩니다.

   > 🔤 **이름이 조금 달라도 웬만하면 알아서 찾습니다.**
   > `참석 여부`(띄어쓰기)처럼 공백·대소문자만 다르면 그대로 인식하고,
   > `상태`·`메모` 처럼 아예 다른 이름이라도 **그 종류의 속성이 DB 에 하나뿐이면** 그것을 씁니다.
   > `참석여부` 를 **선택(Select)** 대신 **상태(Status)** 로 만들어도 동작합니다.
   > 같은 종류가 여러 개라 헷갈릴 때만 7단계에서
   > `NOTION_PROP_NAME` / `NOTION_PROP_STATUS` / `NOTION_PROP_MESSAGE` 환경변수로 정확한 이름을 알려주면 됩니다.

## 2단계 · 인테그레이션(연동) 만들고 토큰 복사

Notion 앱이 아니라 **사파리**에서 해야 합니다.

1. 사파리에서 **https://www.notion.so/my-integrations** 로 들어갑니다.
2. 화면이 모바일용으로 보이면 주소창 왼쪽 **`ᴀA`** → **`데스크탑용 웹사이트 요청`** 을 누르세요. (버튼이 잘 보입니다)
3. **`+ 새 API 통합`**(New integration) 을 누릅니다.
4. 이렇게 채웁니다.
   - **이름**: `동창회 초대장`
   - **연결된 워크스페이스**: 1단계에서 DB를 만든 워크스페이스
   - **유형(Type)**: **내부(Internal)**
5. **`저장`** 을 누릅니다.
6. 다음 화면(또는 `구성`/Configuration 탭)에서 **내부 인테그레이션 시크릿**(Internal Integration Secret) 의
   **`표시`(Show) → `복사`(Copy)** 를 누릅니다.
   - `ntn_` 또는 `secret_` 으로 시작하는 긴 문자열입니다. → 이게 **`NOTION_TOKEN`** 입니다.
7. 아이패드 **메모 앱**에 잠시 붙여넣어 두세요. (7단계에서 씁니다)

> 🔐 이 토큰은 우리 노션을 열 수 있는 열쇠입니다. 카톡·블로그 등에 절대 올리지 마세요.
> 코드에 직접 적지 않고 Cloudflare 환경변수로만 넣습니다.

## 3단계 · 데이터베이스에 인테그레이션 연결하기 ⚠️ 가장 많이 빠뜨리는 단계

토큰만 만들면 노션은 아무것도 안 보여줍니다. **DB를 연동에 "초대"** 해야 합니다.

1. 1단계에서 만든 **`동창회 참석 명단` 페이지**를 엽니다.
2. 오른쪽 위 **`•••`**(점 3개) 를 누릅니다.
3. **`연결`**(Connections) → **`연결 추가`** 를 누릅니다.
4. 목록에서 **`동창회 초대장`** 을 골라 **`확인`/`초대`** 를 누릅니다.
5. `•••` → `연결` 에 **`동창회 초대장`** 이 보이면 성공입니다.

## 4단계 · 데이터베이스 ID 복사하기

1. 다시 **`동창회 참석 명단` 페이지**에서 오른쪽 위 **`•••`** → **`링크 복사`**.
2. 메모 앱에 붙여넣으면 이런 주소가 나옵니다.

   ```
   https://www.notion.so/동창회-참석-명단-1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d?v=98f7...
                                          └──────── 이 32자리가 DB ID ────────┘
   ```

3. **복사한 주소 전체를 그대로 붙여넣어도 됩니다.** 서버가 알아서 32자리 ID만 골라냅니다.
   → 이게 **`NOTION_DB_ID`** 입니다. 메모에 함께 적어두세요.

> ⚠️ 표(데이터베이스)가 다른 페이지 **안에 들어있는 형태(인라인)** 라면,
> 표 제목 위 **`⤢`(전체 페이지로 열기)** 를 눌러 DB 자체를 연 뒤 링크를 복사해야 합니다.
> 바깥 페이지 링크를 넣으면 "데이터베이스를 찾지 못했습니다" 오류가 납니다.

이미 이 저장소를 쓰고 있다면 이 단계는 **건너뛰세요.**

2. 이 저장소 페이지에서 오른쪽 위 **`Fork`** → **`Create fork`** 를 누릅니다.
3. 내 계정에 `reunion-invitation` 저장소가 생기면 끝입니다.

## 6단계 · Cloudflare 에 연결해서 배포하기

Cloudflare 대시보드는 Git 저장소를 연결하면 **Workers 프로젝트**로 만들어 줍니다.
이 저장소는 거기에 맞춰져 있으니 그대로 따라오시면 됩니다.

1. 사파리에서 **https://dash.cloudflare.com** 접속 → 가입/로그인 (무료).
2. 왼쪽 메뉴 **`Compute(Workers & Pages)`** → **`Create`**(만들기).
3. **`Import a repository`**(저장소 가져오기) → **GitHub** 로그인 및 권한 허용.
   - 저장소 선택 화면에서 `reunion-invitation` 만 골라도 됩니다.
4. 저장소 목록에서 **`reunion-invitation`** 을 선택합니다.
5. 설정 화면은 이렇게 둡니다. 👇

   | 항목 | 값 |
   |---|---|
   | Project name | **`reunion-invitation`** (⚠️ 아래 주의사항 참고) |
   | Branch | 배포할 브랜치 (보통 `main`) |
   | Build command | **비워두기** |
   | Deploy command | **`npx wrangler deploy`** (기본값 그대로) |
   | Root directory | **`/`** |

   > ⚠️ **프로젝트 이름 주의**: 여기서 정한 이름은 저장소의 `wrangler.jsonc` 안
   > `"name"` 값과 **같아야 합니다.** 기본값 `reunion-invitation` 을 그대로 쓰면 문제없고,
   > 다른 이름으로 만들었다면 8단계 방법으로 `wrangler.jsonc` 의 `"name"` 을 그 이름으로 고쳐주세요.

   > ⚠️ **브랜치 주의**: 아직 작업 브랜치를 `main` 에 합치지 않았다면,
   > Branch 를 작업 브랜치로 지정하거나 먼저 PR 을 머지하세요.
   > 안 그러면 `README.md` 만 있는 `main` 이 배포됩니다.

6. **`Deploy`** 를 누릅니다. 1~2분 뒤 `https://프로젝트이름.계정이름.workers.dev` 주소가 나옵니다.
7. 지금 열어보면 화면은 나오지만 명단 자리에 **"서버 설정이 끝나지 않았습니다"** 라고 보일 겁니다. → 정상입니다. 7단계로!

### 이미 만들었는데 배포가 실패했다면

빌드 로그에 이런 오류가 보이는 경우입니다.

```
Executing user deploy command: npx wrangler deploy
✘ [ERROR] Could not detect a directory containing static files (e.g. html, css and js)
```

저장소에 `wrangler.jsonc` 와 `public/` 폴더가 없어서 나는 오류입니다. **지금은 둘 다 들어 있으니**,
그 커밋이 포함된 브랜치가 배포 대상인지 확인한 뒤 **`Deployments` → `Retry deployment`**(다시 시도)
또는 **`Create deployment`** 를 누르면 됩니다.

### (다른 방법) Cloudflare Pages 로 배포하고 싶다면

`functions/api/*.js` 는 Pages Functions 규격 그대로라 Pages 로도 배포됩니다.

1. 저장소에서 **`wrangler.jsonc` 파일을 삭제**합니다. (Pages 는 `main` 키가 있는 설정 파일을 거부합니다)
2. Workers & Pages → Create → **`Pages`** 탭 → Connect to Git → 저장소 선택
3. 빌드 설정: Framework preset **None**, Build command **비워두기**,
   **Build output directory `public`**
4. 주소는 `https://프로젝트이름.pages.dev` 형태가 됩니다.

## 7단계 · 환경변수 등록하고 다시 배포하기

1. 방금 만든 프로젝트 → **`Settings`**(설정) → **`Variables and Secrets`**
   (예전 화면에서는 `Environment variables`).
2. **`+ Add`** 를 눌러 두 개를 넣습니다.

   | 이름(Variable name) | 종류 | 값 |
   |---|---|---|
   | `NOTION_TOKEN` | **Secret** | 2단계에서 복사한 `ntn_...` 토큰 |
   | `NOTION_DB_ID` | **Secret** | 4단계에서 복사한 DB ID(또는 노션 링크 전체) |

   > 💡 **둘 다 `Secret` 으로 넣으세요.** 일반 Text 로 넣으면 다음 배포 때
   > `wrangler deploy` 가 설정 파일 기준으로 덮어써서 값이 사라질 수 있습니다.
   > (Secret 은 배포와 상관없이 그대로 유지됩니다)

   > 선택 사항: 1단계에서 속성 이름을 다르게 지었다면 아래도 함께 넣으세요.
   > `NOTION_PROP_NAME`(기본 `이름`) · `NOTION_PROP_STATUS`(기본 `참석여부`) · `NOTION_PROP_MESSAGE`(기본 `한마디`)

3. **`Save`**(또는 `Deploy`) 를 누릅니다.
   Workers 는 값을 저장하면 **새 버전이 곧바로 배포**되므로, 보통 이걸로 끝입니다.
4. 사이트를 새로고침하고 이름을 넣어 **참석 투표를 눌러보세요.**
   노션 표에 행이 새로 생기면 **성공입니다!** 🎉

### 그래도 "서버 설정이 끝나지 않았습니다" 가 그대로라면

빌드를 한 번 다시 돌리면 됩니다. 방법은 세 가지이고, 아무거나 하나면 됩니다.

- **`Deployments` 탭 → 목록에서 최근 빌드를 눌러 상세 화면 → 오른쪽 위 `Retry build`**
  (버튼이 안 보이면 화면을 **맨 위까지 스크롤**해 보세요. 로그를 보고 있으면 버튼이 화면 밖에 있습니다)
- **`Settings` → `Build` → `Retry build`**
- **GitHub 저장소에 아무 커밋이나 하나 push** — 커밋될 때마다 빌드가 자동으로 돕니다.
  (예: `README.md` 를 아주 조금 고쳐서 커밋)

## 8단계 · 우리 동창회 내용으로 바꾸기

아이패드에서 **GitHub 웹 화면으로 바로 수정**할 수 있습니다.
파일을 저장(커밋)하면 Cloudflare가 **자동으로 다시 배포**합니다. (1~2분 소요)

### (1) 초대장 내용 — `assets/js/config.js`

1. GitHub 저장소 → `public` → `assets` → `js` → **`config.js`** 를 누릅니다.
2. 오른쪽 위 **연필(✏️) 아이콘** → 내용을 고칩니다.
3. 아래로 내려 **`Commit changes`** → **`Commit changes`** 를 누릅니다.

고칠 항목입니다.

| 항목 | 설명 |
|---|---|
| `title` / `subtitle` / `hostLine` | 첫 화면 제목·부제·주최 |
| `date` | 카운트다운 기준 시각. **`'2026-11-14T18:00:00+09:00'` 형식 그대로** (한국시간 `+09:00` 유지) |
| `dateText` | 화면에 보이는 일시 문구 |
| `placeName` / `placeAddress` / `placeDetail` | 장소·주소·교통·주차 안내 |
| `fee` / `feeDetail` | 회비와 입금 계좌 |
| `kakaoMapUrl` / `naverMapUrl` | 지도 링크 (아래 참고) |
| `contactName` / `contactPhone` | 문의 담당자. 전화 버튼을 없애려면 `contactPhone: ''` |
| `greeting` | 인사말. 줄마다 `'...'`, 로 나열하면 됩니다 |
| `rsvpDeadline` | 투표 마감 시각. 안 쓰려면 `null` |

**지도 링크 얻는 법(아이패드)**
- 카카오맵: 앱/웹에서 장소 검색 → **공유** → **링크 복사** → `kakaoMapUrl` 에 붙여넣기
- 네이버지도: 장소 검색 → **공유** → **URL 복사** → `naverMapUrl` 에 붙여넣기
- 링크를 `''` (빈 따옴표) 로 두면 그 버튼은 자동으로 숨겨집니다.

### (2) 카카오톡 미리보기 — `public/index.html` 상단 OG 태그

`public/index.html` 을 열면 위쪽에 주석으로 표시된 부분이 있습니다. 5줄만 고치면 됩니다.

```html
<title>제12회 한빛고 총동창회 초대장</title>
<meta name="description" content="...">
<meta property="og:title" content="제12회 한빛고 총동창회에 초대합니다">
<meta property="og:description" content="2026년 11월 14일 (토) 오후 6시 · 그랜드컨벤션 3층">
<meta property="og:image" content="https://내주소.workers.dev/assets/img/og.png">
<meta property="og:url" content="https://내주소.workers.dev">
```

- `og:url` 과 `og:image` 는 **반드시 `https://` 로 시작하는 전체 주소**여야 합니다.
  6단계에서 받은 실제 주소(`*.workers.dev` 또는 `*.pages.dev`)를 넣으세요.
- **미리보기 이미지 올리는 법**: 아이패드에서 **1200×630** 크기 이미지를 만들고(캔바 등)
  GitHub 저장소 → `public` → `assets` → `img` 폴더 → **`Add file` → `Upload files`** 로 **`og.png`** 라는 이름으로 올립니다.
- 카톡에 한 번 공유한 링크는 미리보기가 캐시됩니다. 바꾼 뒤에도 예전 화면이 보이면
  **카카오 공유 디버거**(https://developers.kakao.com/tool/debugger/sharing) 에서 주소를 넣고 **초기화**하세요.

## 🔌 API 명세

프론트엔드에서 쓰는 두 개의 주소입니다. (Notion 토큰은 서버에만 있고 브라우저로 내려가지 않습니다)

### `GET /api/attendees`

```json
{
  "ok": true,
  "counts": { "total": 20, "축구부터": 8, "저녁부터": 6, "뒷풀이부터": 2, "불참": 4, "기타": 0 },
  "attendees": [
    { "name": "김제균", "status": "축구부터", "message": "보고싶다!", "updatedAt": "2026-09-01T10:00:00.000Z" }
  ]
}
```

- 최근에 응답/수정한 사람이 위로 옵니다.
- `이름`이 비어 있는 행은 명단에서 빠집니다.

### `POST /api/rsvp`

요청 본문:

```json
{ "name": "김제균", "status": "저녁부터", "message": "늦게라도 갈게요" }
```

- `status` 는 `축구부터` · `저녁부터` · `뒷풀이부터` · `불참` 중 하나여야 합니다.
  (목록에 없는 값이 노션에 들어 있으면 화면에는 `기타` 로 표시됩니다)
- `name` 최대 30자, `message` 최대 200자 (넘으면 잘립니다).
- **같은 이름이 이미 있으면 새 행을 만들지 않고 그 행을 수정합니다.**
  `김 한빛` 처럼 띄어쓰기·대소문자만 다른 경우도 같은 사람으로 봅니다.

응답:

```json
{ "ok": true, "updated": true, "attendee": { "name": "김제균", "status": "저녁부터", "message": "늦게라도 갈게요" } }
```

- `updated: true` 면 기존 응답 수정, `false` 면 새로 추가된 것입니다.
- 실패하면 `{ "ok": false, "error": "사람이 읽을 수 있는 안내 문구" }` 가 옵니다.

## 🩺 문제가 생겼을 때

| 화면에 보이는 문구 | 원인과 해결 |
|---|---|
| **서버 설정이 끝나지 않았습니다** | 환경변수(`NOTION_TOKEN`·`NOTION_DB_ID`)가 아직 안 들어갔습니다. 7단계를 확인하고, 그래도 그대로면 빌드를 한 번 다시 돌리세요. |
| **Notion 토큰이 올바르지 않습니다** | `NOTION_TOKEN` 값에 공백이나 따옴표가 섞였는지 확인하세요. 2단계에서 다시 복사해 붙여넣습니다. |
| **데이터베이스를 찾지 못했습니다** | 대부분 **3단계(연결 추가)** 를 안 한 경우입니다. 또는 DB ID가 바깥 페이지 링크일 수 있습니다(4단계 ⚠️ 참고). |
| **Notion DB 에 이 속성이 없습니다 → …** | 오류 문구가 **없는 속성**과 **지금 DB 에 있는 속성**을 그대로 알려줍니다. 노션에서 표 오른쪽 끝 `+` 로 빠진 속성을 추가하세요. (1단계 표 참고) |
| **요청이 잠시 많습니다** | Notion API 속도 제한입니다. 몇 초 뒤 새로고침하면 됩니다. |
| 명단은 되는데 **투표만 안 됨** | 인테그레이션 권한 문제입니다. 3단계에서 연결을 지웠다가 다시 추가해 보세요. |
| **Could not detect a directory containing static files** | 배포 대상 브랜치에 `wrangler.jsonc` 와 `public/` 폴더가 없습니다. 브랜치 설정을 확인하고 다시 배포하세요. (6단계 아래 "이미 만들었는데 배포가 실패했다면") |
| **Worker 이름이 다르다는 오류 / 엉뚱한 주소로 배포됨** | `wrangler.jsonc` 의 `"name"` 을 대시보드의 프로젝트 이름과 똑같이 맞추세요. |
| **잘 되다가 갑자기 "서버 설정이 끝나지 않았습니다"** | 환경변수를 Text 로 넣어서 재배포 때 지워졌을 수 있습니다. **Secret** 으로 다시 등록하세요. |
| **화면이 아예 안 바뀜** | Cloudflare 배포가 끝났는지 `Deployments` 탭에서 확인하고, 사파리에서 새로고침을 길게 눌러 강력 새로고침 하세요. |

배포 로그는 Cloudflare **`Deployments` → 해당 배포 → `Functions` 로그**에서 볼 수 있습니다.

## 🖥️ (선택) PC에서 로컬로 돌려보기

아이패드만 쓴다면 필요 없습니다.

```bash
# 토큰은 .dev.vars 파일에 적습니다 (git에 올라가지 않습니다)
printf 'NOTION_TOKEN=ntn_xxx\nNOTION_DB_ID=xxxx\n' > .dev.vars
npx wrangler dev
```

브라우저에서 `http://localhost:8787` 로 접속합니다.
배포 전에 설정만 점검하려면 `npx wrangler deploy --dry-run` 을 쓰세요.

- 행사가 끝나면 Cloudflare 프로젝트를 삭제하거나 노션 DB를 정리해 주세요.
