# 원본 이미지 보관함

여기 있는 파일은 **웹사이트로 배포되지 않습니다.** (배포되는 건 `public/` 폴더뿐)
`public/assets/img/` 에 들어가는 이미지의 원본을 잃어버리지 않도록 보관하는 곳입니다.

| 원본 | 사용처 | 처리 |
|---|---|---|
| `IMG_0298.png` (1408×768, 1.05MB) | 히어로 서예 | 여백을 잘라내고 조명 얼룩(비네팅)을 보정한 뒤 종이 부분을 투명하게 → `public/assets/img/hero.png` (215KB, 화면용) / 카톡 미리보기(OG)용 흰 배경 JPEG 은 `hero.jpg` (51KB) |
